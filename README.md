# 她说 Her Mood · 哄哄模拟器

一个单文件 3D 网页小游戏：用 **Jev（TypeSafe System One 模型）** 当她的"内心裁判"。
目标是在 **10 回合内把「心情」哄到 85 以上**。

---

## 玩法（先探知，再行动）

1. 她抛出一句台词（如"随便你吧。"）。
2. 点 **「探知她的想法」** —— 游戏把她的可见状态和 `Choice` 问题发给 Jev，
   读回她"最想要哪种陪伴"的**概率分布**与 **confidence**，显示在右侧判决面板。
3. **每个选项按钮右上角会直接标注**：中文档位名 + 该策略的概率，
   概率最高的一项绿框高亮并带 **★推荐**。
4. 你据此选一句回应 → 结算心情增减（`Score` / `Noul`）。

> **迷雾机制**：当 confidence 很低（< 50%），概率会被摊平——标了"★推荐"的也未必是真相，得赌一把。

键盘：`空格/Enter` 探知，`1`–`6` 选对应选项。

---

## 两种判决引擎

在「配置问题与答案 → 连接」里切换：

| 模式 | 说明 |
|------|------|
| **本地启发式** | 默认，离线可用，无需 Key，开箱即玩 |
| **真实 Jev API** | 概率由模型真实返回；调用失败自动回退本地 |

---

## 用真实 Jev：必须先跑代理

官方 `api.typesafe.ai` **不放行浏览器跨域直连**（OPTIONS 预检会被拒，表现为 `Failed to fetch`），
所以要用随附的零依赖代理脚本 `jev_proxy.py`：

```bash
python jev_proxy.py            # 默认端口 8010
# 或自定义端口
python jev_proxy.py --port 9000
```

然后在游戏配置里：

- 判决引擎：**真实 Jev API**
- API 端点：填脚本启动时打印的地址（形如 `http://127.0.0.1:8010`）
- API Key：你的 `ts_...` 密钥
- 点 **「测试连接」** 验证通不通

> Key 只经本机转发给官方，脚本不记录、不上传。

## 可配置问题与答案

配置面板里可自由编辑发给 Jev 的**问题**与**答案档位**：

- **want**（Choice）：她想要什么 → 决定探知阶段的概率分布
- **mood**（Score）：情绪档位 → 其分数决定心情增减
- **modifier**（Noul）：附加判断题 → 会不会火上浇油

选项按钮由 **want 题的档位（criteria）驱动**：配置里加几档，就出几栏对应选项。
配置保存在浏览器本地，可导入 / 导出。

---

## 常见问题

- **报 400 / Failed to fetch**：多为端点拼写或跨域问题。官方端点是无连字符的
  `https://api.typesafe.ai/v1/systemone`；直连官方域名会被 CORS 拦，请改用上面的代理。
- **每次选项都一样**：选项已改为每回合随机抽取，且完全由 want 配置驱动。
- **看不懂该选哪个**：看选项按钮右上角的中文角标 + 概率，标「★推荐」的是当前最高项。
